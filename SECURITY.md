# Security Policy

## Supported Versions

VentoryGo is in active development and has no released versions yet. Only the current
`main` branch receives fixes.

## Reporting a Vulnerability

Please do not open a public issue for security problems.

Use GitHub's [private vulnerability reporting](../../security/advisories/new) instead.
Include the affected endpoint or component, steps to reproduce, and what an attacker
could achieve.

Expect a first response within a few days. This is a side project, not a product with
an on-call rotation.
